# Security and privacy

This project processes user-authorized saved content. It must not be used to bypass authentication, CAPTCHA, private-account controls, rate limits, or platform restrictions.

## Do not disclose

Do not attach any of the following to a public issue or pull request:

- passwords, cookies, access tokens, browser profiles, or session exports;
- private collection screenshots or personal browsing history;
- generated `project.json`, `items.json`, reports, or CSV files containing personal data;
- content from private accounts that you are not authorized to redistribute.

## Reporting a problem

Open a public issue only when it can be reproduced with fictional data. For a sensitive report, contact the repository owner privately through the contact method listed on their GitHub profile.

## Supported use

Use a human-paced, user-visible workflow. Keep authentication inside the user's chosen browser and store checkpoints locally. Stop when the host product or website asks the user to take over login or security verification.
